# 26H：第二至六问脱机测评固件

`26H` 是正式测评唯一需要烧录的 MSPM0G3507 工程。上电后仅使用 OLED 与
PA18/BLS 选择题目；各题之间通过复位或重新上电切换，上电前必须人工把球杆
调到水平，软件把该位置视为相对 0 步。

## 上电菜单

OLED 同屏显示 `2`、`3`、`4`、`5&6`，`>` 表示当前选项。

- 单击：释放后等待 300 ms，随后移动到下一项；
- 双击：300 ms 内完成第二次点击，进入当前项且不移动选择；
- 长按：菜单、第二问、第四问及 5&6 模式均忽略；
- 按住 BLS 上电：必须先松开，松开动作不会被识别为点击。

题目流程和异常提示见 [JUDGE_GUIDE.md](JUDGE_GUIDE.md)。

## 控制器边界

- 第二问使用 `track` 的高速配置：PWM 3000/1800、斜率 200、P/D 5/10，
  38000 编码计数且运行 10 s 后才允许识别终点，连续两帧宽线后立即刹车。
- 第四至六问使用独立稳定配置：PWM 2500/1000、斜率 100、P/D 8/16；
  起步前预载 100 ms，车轮在 500 ms 内渐升。控制器以两轮公共 PWM 每 5 ms
  的计划增量估算前进加速度：死区为 2、增益为 0.96 微步/增量，当前配置得到
  `+24` 微步的球杆前端下降前馈并限幅在 `+/-24`；渐升结束后按每 5 ms 2 微步
  平滑回零，最长 60 ms。
- 第四至六问均关闭终点识别和运行超时，经过 B、A 或宽线后继续循迹；正常
  结束方式只有复位或断电。OLED 计时达到 `30.0s` 后仅显示饱和，不影响运行。
- 所有巡线模式失线时均冻结最后一次 PID 修正并继续输出。第二问仍保留
  编码器堵转、20 s 超时和终点刹车；第四至六问继续关闭堵转、超时和
  终点停车。
- 第二问完成或故障后不会再次执行巡线 PWM tick；第四至六问起车后保持活动
  状态，不提供运行中按键急停。

高速和稳定两组参数分别位于 `app_config.h` 的 `APP_Q2_*` 与 `APP_Q456_*`
区域。现场调节稳定模式不得改动第二问参数。

## 钢球与 K230

- K230 IO3/UART1_TXD → MSPM0 PB7/UART1_RX；
- MSPM0 PB6/UART1_TX → K230 IO4/UART1_RXD；
- PB16/TIMG7_C1 → D36A STEP1，PB17 → DIR1，PA24 → EN1/SLEEP#；
- UART 为 115200、8N1，所有模块共地。

菜单、第二问和第三问期间关闭 K230 UART IRQ。进入第四问或 5&6 后清空硬件
FIFO、软件队列和解析状态，只接受本次模式的新帧。两端解析器都以 20 ms
帧间字节超时恢复截断帧。

第四问把目标永久锁定为 O；5&6 确认前允许触摸选点，确认后 MCU 锁定目标并
在状态帧中返回锁定标志，K230 随后禁止拖动并以 MCU 目标为准。

K230 上电入口为 `K230/li.py`，平台实现为
`K230/steel_ball_motion_wifi_320_full_v3.py`。需要部署 `YOLO.py` 和
`best_v2.kmodel`。Wi-Fi/AP 最多等待 2 s；失败时本次上电关闭网络图传，
LCD、识别和 UART 仍继续运行。

## 已知硬件前提

- 软件安全行程为 `-238..238` 微步；无编码器、限位开关或绝对零点。
- D36A 使用 1/16 细分和约 0.55 A 初始电流档。
- 编译成功不代表已经验证机械行程、方向、灰度极性、UART 波形或实车成绩。
