# 26H 第五问：启停角度补偿与终点平滑停车

本工程在 MSPM0G3507 上同时运行第二问循迹和 D36A 球杆闭环。两个控制器仍各自维护状态和故障；底盘只在启动、终点减速阶段向球控提供短时角度前馈，不等待钢球稳定，也不根据球控状态改变循迹。PA18 长按 2 秒仍是唯一全系统急停。

## 当前配套程序

- CCS 工程：`question5`
- K230 入口：当前实际烧录的 `li(1).py`
- K230 平台模块：当前实际烧录的 `steel_ball_motion_wifi_320_full_v3.py`
- 通信：115200、8N1，MSPM0 PB7 接收、PB6 发送
- K230 红线默认位置：`x=171`；运行中拖动红线会更新球控目标

K230 文件、UART 帧格式和全部引脚分配均未修改。OLED 的 SysConfig 只把 PB14/RST 上电初值从高改为低，以保证控制器从系统初始化开始一直处于可靠复位。工程内 `k230/steel_ball_motion_question5.py` 仅为历史参考文件，不应覆盖当前 K230 程序。

OLED 上电时由 PB14 持续拉低复位，释放后等待 120 ms 再初始化。应用启动顺序固定为 `SYSCFG_DL_init()` 完成基础引脚配置后立即初始化 OLED，随后才初始化电机、循迹传感器、UART 和球杆驱动，避免后续驱动初始化干扰 OLED GPIO。初始化成功时会先全屏点亮约 300 ms，随后显示 `0.0s`；这段自检只在上电或复位时执行，不影响循迹周期。

## PA18 操作

PA18 使用 30 ms 消抖，短按在按键松开后确认。

1. 上电前手动把球杆调到近似水平，该机械位置作为软件零位。
2. 上电后第一次短按只启动钢球闭环，底盘保持刹车；该次短按不计入循迹双击。
3. 球控启动后，第一次短按只记录循迹双击的第一击。
4. 1000 ms 内再次短按后启动循迹，30 秒计时从第二次按键松开时开始。
5. 启动后先保持底盘刹车 100 ms，同时施加启动角度补偿；随后电机在 500 ms 内由 0 平滑增加到正常循迹 PWM，之后自动清除启动补偿。
6. 单击超过 1000 ms 不执行动作；循迹正在运行、启动预倾或终点减速期间的双击也不重启。
7. 底盘空闲、完成或底盘故障后，可以再次双击重新启动循迹。
8. 长按 2 秒使底盘和 D36A 同时急停并锁存，必须重新上电恢复。

## 启停角度补偿参数

参数集中位于 `app_config.h`：

```c
#define APP_Q5_BALL_START_ACCEL_COMP_STEPS     (12.0f)
#define APP_Q5_BALL_BRAKE_ACCEL_COMP_STEPS    (-12.0f)
#define APP_Q5_BALL_ACCEL_COMP_LIMIT_STEPS      (24.0f)
```

- `APP_Q5_BALL_START_ACCEL_COMP_STEPS`：启动补偿。当前默认 `+12` 微步；若启动时钢球仍向左、K230 的 x 减小，可每次增加 2～4；若偏移变严重，减小或改成负值。
- `APP_Q5_BALL_BRAKE_ACCEL_COMP_STEPS`：刹车补偿。当前默认 `-12` 微步；若刹车时钢球仍向右、x 增大，可每次增加负值绝对值 2～4；若偏移变严重，向 0 调或改成正值。
- `APP_Q5_BALL_ACCEL_COMP_LIMIT_STEPS`：前馈软件限幅，默认最多 ±24 微步。补偿与视觉 PD 输出相加后仍受原有球杆 ±64 微步工作角限制。

接口为 `ball_rod_set_chassis_accel_compensation_steps(float steps)`，补偿会叠加到 HOLD 和 ACTIVE 两种球控输出。普通底盘故障、完成和全局急停会立即清零补偿，随后球控依靠视觉 PD 回到红线位置。

## 终点判定与一秒停车

- 终点判据仍是至少四路相邻灰度通道识别到黑线，并连续确认两次。
- 终点判据仍保留最小时间和编码器里程使能，避免起点宽线误触发。
- 确认终点后立即施加刹车角度补偿，并以 `APP_Q5_FINISH_ALIGN_PWM` 低速继续 PID 循迹 100 ms。
- 随后 900 ms 内，基础 PWM 和左右差速修正按相同比例线性下降到 0；总计 1000 ms 后底盘刹车并进入完成状态。
- 终点减速阶段暂时关闭编码器堵转判定，避免低 PWM 无脉冲误报；丢线、30 秒超时和全局急停仍有效。

停车距离参数也在 `app_config.h`：

```c
#define APP_Q5_FINISH_TOTAL_MS                 (1000U)
#define APP_Q5_FINISH_PRELOAD_MS                (100U)
#define APP_Q5_FINISH_ALIGN_PWM                (1800U)
```

`APP_Q5_FINISH_ALIGN_PWM` 专门用于实车标定终点后的行驶距离：不足约 34 cm 时小幅增加，超过约 34 cm 时降低。当前使用线性 PWM 下降来近似恒减速，并非 MPU6050 闭环物理恒加速度；本版本不启用 MPU6050。

## 解耦规则

- 每个 5 ms 周期独立执行球控服务和循迹服务。
- K230 视觉丢失、钢球超差、球杆软件限位或球控故障只影响球杆，不改变底盘状态和 PWM。
- 丢线、编码器堵转、到达终点或循迹 30 秒超时只影响底盘，不停止球控。
- 启动和终点阶段的角度前馈是预定的扰动补偿，不读取钢球状态，也不构成发车联锁。
- 拖动 K230 红线只更新球控目标，不修改循迹状态、速度或计时。
- 完成一圈后底盘刹车、PB9 熄灭、OLED 冻结时间，球控继续运行。

## 上车验证

1. 第一次短按后确认只有 D36A 球杆动作，底盘保持刹车。
2. 双击后确认底盘静止 100 ms、球杆正向预倾，随后 500 ms 平滑加速且补偿自动清零。
3. 启动偏移较大时，每次只调整启动补偿 2～4 微步，并检查球杆未触及软件工作角限制。
4. 普通零散黑线或不足四路相邻黑线不得触发停车。
5. 连续两次检测到至少四路相邻黑线后，确认前 100 ms 低速循迹、后 900 ms 两轮输出和转向修正同步下降，1 秒后刹停。
6. 调整 `APP_Q5_FINISH_ALIGN_PWM`，使检测启停线后行驶距离接近 34 cm。
7. 按 2～4 微步调整负向刹车补偿，确认刹车时向右偏移减小。
8. K230 丢失或球控故障时确认底盘不受影响；底盘丢线或故障时确认球控继续运行且前馈清零。
9. 长按 PA18 两秒，确认底盘和球杆同时急停，且重新上电前不能恢复。
