# 26H 第五问：循迹与钢球平衡完全解耦

本工程在 MSPM0G3507 上同时运行第二问循迹和 D36A 球杆闭环。两个控制器各自维护状态，除 PA18 长按 2 秒的全系统急停外，互不启动、停止或降速。

## 当前配套程序

- CCS 工程：`question5`
- K230 入口：当前实际烧录的 `li(1).py`
- K230 平台模块：当前实际烧录的 `steel_ball_motion_wifi_320_full_v3.py`
- 通信：115200、8N1，MSPM0 PB7 接收、PB6 发送
- K230 红线默认位置：`x=171`；运行中拖动红线会发送新目标给球控

K230 两个文件不需要修改。工程内旧的 `k230/steel_ball_motion_question5.py` 仅是历史参考文件，不应覆盖当前 K230 程序。

## PA18 操作

PA18 使用 30 ms 消抖，短按在按键松开后确认。

1. 上电前手动把球杆调到近似水平；该机械位置作为软件零位。
2. 上电后第一次短按：只启动钢球闭环，底盘保持刹车；本次短按不计入循迹双击。
3. 球控启动后，短按一次：只记录循迹双击的第一次点击。
4. 在 1000 ms 内再短按一次：立即启动或重新启动循迹，并从此刻开始 30 秒计时。
5. 第一次点击超过 1000 ms 未等到第二次点击：不执行任何动作。
6. 长按 2 秒：底盘和 D36A 同时急停并锁存，必须重新上电才能恢复。

## 完全解耦规则

- 每个 5 ms 周期都独立执行球控服务和循迹服务。
- K230 视觉丢失、钢球超差、球杆软件限位或球控故障，只影响球杆，不改变底盘状态和 PWM。
- 丢线、编码器堵转、到达终点或循迹 30 秒超时，只影响底盘，不停止球控。
- 循迹启动不等待钢球稳定，也不检查视觉、球位、球控状态或球杆限位。
- 拖动 K230 红线只更新球控目标，不修改循迹状态、速度或计时。
- 完成一圈后底盘刹车，球控继续运行；再次双击可重新开始循迹。

## 底盘显示

PB9 与 OLED 只表示底盘状态，钢球状态继续由 K230 LCD 显示。

- PB9 熄灭：底盘空闲或循迹完成
- PB9 常亮：底盘正在循迹
- PB9 快闪：底盘故障或全局急停
- OLED：循迹时显示从双击成功开始的时间；完成后冻结；底盘故障显示 `Err`

## 主要文件

- `empty.c`：PA18 手势、两个独立状态机、循迹 PID、终点判断、PB9/OLED
- `ball_rod_control.c`：钢球位置闭环与球杆自身安全状态机
- `ball_stepper.c`：D36A STEP/DIR/EN、加减速和软件行程限制
- `ball_protocol.c`：K230 双向 UART 协议及可拖动目标帧
- `motor_control.c`：底盘电机、编码器和堵转检测
- `app_config.h`：循迹、球控和第五问计时参数

## 上车验证

1. 第一次短按后确认只有 D36A 动作，两个底盘电机保持刹车。
2. 球控启动后单独短按一次，等待超过 1000 ms，确认底盘不启动。
3. 在 1000 ms 内完成两次短按，确认底盘立即循迹且 OLED 从 `0.0s` 开始计时。
4. 在钢球未稳定、K230 断开或球控故障时双击，确认底盘仍可独立循迹。
5. 循迹中断开 K230，确认底盘继续；制造丢线或堵转，确认底盘刹车而球控继续。
6. 拖动 K230 红线，确认球杆目标改变，而底盘 PWM、状态与计时不受影响。
7. 完成一圈后确认球控继续；再次双击确认可重新循迹。
8. 长按 PA18 两秒，确认底盘与球杆都急停，短按不能恢复，重新上电后才能恢复。
