# test3：第三问纯开环滚球

本工程只完成 H 题第三问：小车保持静止，双击 BLS 后，MSPM0G3507
直接按硬编码轨迹控制 D36A 和球杆步进电机。控制过程不读取 K230、灰度
传感器或底盘编码器。

## 使用前提

上电和调平顺序：

1. 先给 MSPM0 上电；固件会立即把 PA24/EN 保持为高电平；
2. 打开 D36A 独立电源，使用 BLS 单击/长按把水管电动调到水平；
3. 把钢球放在中心点 O，然后双击 BLS 开始；
4. D36A 使用 1/16 细分，电流仍为约 0.55 A；
5. 球杆机构没有卡滞，软件安全行程仍为 `-238～+238` 微步。

系统没有杆角编码器、限位开关和球位置反馈。开环只能重复相同动作，不能
自动修正电池电压、摩擦、装配间隙或失步引起的终点漂移。

## BLS 动作

- 单击：释放后等待 350 ms；确认不是双击后，沿当前方向移动 4 微步。
- 长按 1000 ms：只切换下一次调节方向，保持按住不会重复切换，释放也不移动。
- 双击：第二次短按释放后，以当前物理位置作为本轮水平零点并立即开始第三问。
- 第一次短按不会提前移动，因此双击启动不会夹带调节步。
- 运行过程中再次按 BLS：完全忽略，不改变当前轨迹。
- 故障状态：需要重新上电。
- 完成后可以继续单击/长按调平，也可以放回 O 点后直接双击再次运行。

调平时 OLED 上行显示下一次软件方向 `DIR+` 或 `DIR-`，下行显示以上电位置
为 0 的累计微步，例如 `+012`、`-008`。正负号只代表软件方向，不代表固定的
机械“上/下”。调平不再设置独立的 `±64` 限制；它只与正式轨迹共同遵守机构
已经标定的 `-238～+238` 整体安全软行程。

默认时序：

```text
确认 EN 为高并等待 2 ms
  -> 本轮零点到 +104 微步，240 Hz
  -> 不停留，立即反向到 -48 微步，300 Hz
  -> 保持 1200 ms
  -> 提前回到本轮零点，240 Hz
  -> 水平保持 1000 ms
  -> COMPLETE
```

完成后 STEP 保持低电平，PA24/EN 保持高电平，以保持球杆水平。OLED 显示
从双击启动到稳定完成的时间；进行调节后重新显示调平界面。运行时 LED 常亮，
完成后熄灭，故障时快闪。

## 调参位置

只修改 `app_config.h` 最上面的 `OPEN LOOP USER TUNING` 区域：

```c
#define APP_BALL_DIR_INVERT       (0U)
#define APP_OL_LAUNCH_STEPS       (104)
#define APP_OL_LAUNCH_HOLD_MS     (0U)
#define APP_OL_REVERSE_STEPS      (-48)
#define APP_OL_RETURN_HOLD_MS     (1200U)
#define APP_OL_LAUNCH_HZ          (240U)
#define APP_OL_REVERSE_HZ         (300U)
#define APP_OL_LEVEL_HZ           (240U)
#define APP_OL_FINAL_SETTLE_MS    (1000U)
#define APP_OL_RUN_TIMEOUT_MS     (4500U)
#define APP_TRIM_STEP_SIZE        (4)
#define APP_TRIM_HZ               (120U)
#define APP_BUTTON_LONG_PRESS_MS  (1000U)
#define APP_BUTTON_DOUBLE_CLICK_MS (350U)
```

### 1. 先确认方向

第一次必须拿掉钢球测试。

- 默认 `APP_BALL_DIR_INVERT=0U`。
- 第一段应让电机侧降低，使球装上后向电机侧/+5 cm 方向滚动。
- 如果第一段方向相反，只把 `APP_BALL_DIR_INVERT` 改成 `1U`，不要交换电机线。
- 调平界面的 `DIR+` 与正式第一段使用相同的软件正方向；长按可在 `DIR+`
  和 `DIR-` 之间切换。

### 2. 调整启动力度

先调整 `APP_OL_LAUNCH_STEPS`：

- 球不动或启动不可靠：`104 -> 112`，每次增加 8 微步。
- 球冲得过快：`104 -> 96`，每次减少 8 微步。
- 默认立即反向，所以 `APP_OL_LAUNCH_HOLD_MS=0U`。只有确认杆角有效但球仍
  来不及启动时，才按 `25 ms` 增加该值。

### 3. 调整 +5 cm 折返点

主要调整 `APP_OL_REVERSE_STEPS`，保持它为负数：

- 球未到 +5 cm 就折返：减小绝对值，例如 `-48 -> -44 -> -40`。
- 球越过 +5 cm 才折返：增大绝对值，例如 `-48 -> -52 -> -56`；
  也可以把 `APP_OL_LAUNCH_STEPS` 减少 8。

每次只改 4～8 微步，然后重新构建、烧录和测试。

### 4. 调整 -5 cm 最终位置

主要调整 `APP_OL_RETURN_HOLD_MS`：

- 最终停不到 -5 cm：增加，例如 `1200 -> 1250 -> 1300 ms`。
- 最终越过 -5 cm：减少，例如 `1200 -> 1150 -> 1100 ms`。

每次只改 25～50 ms。这个保持时间从电机实际到达反向倾角后开始计时，因此
改变 STEP 频率不会偷偷改变保持时间。

`APP_OL_FINAL_SETTLE_MS` 只决定杆回平后等待多久才显示完成，不直接改变球的
终点。STEP 频率只用于解决杆动作太慢、明显振动或疑似失步，不要优先用频率
调整 ±5 cm 位置。

## 安全限制

- `APP_OL_LAUNCH_STEPS` 和 `APP_OL_REVERSE_STEPS` 必须位于
  `-238～+238` 微步。
- 三段 STEP 频率必须位于 `80～300 Hz`。
- `APP_OL_RUN_TIMEOUT_MS` 必须小于 5000 ms。
- 调平没有独立上限；到达机构整体 `-238～+238` 安全软行程后，继续向外
  单击不会移动。
- 双击启动前应确保当前调平位置为真实水平位置；若从严重偏离上电原点的位置
  启动，正式轨迹目标可能受到整体安全软行程裁剪。
- 编译期会计算理论动作时间；若调参后理论时间不再小于超时值，编译直接报错。
- 运行超过 4500 ms 仍未完成时，固件命令球杆回到双击捕获的本轮零点，
  随后进入故障。

## 固定接线

| 功能 | MSPM0 | D36A |
|---|---|---|
| STEP | PB16 / TIMG7_C1 | STEP1 / P1-8 |
| DIR | PB17 | DIR1 / P1-6 |
| EN | PA24 | EN1 / P1-4 |
| BLS | PA18，高有效 | - |

所有模块必须共地。D36A 继续使用 7.4 V 电池原始支路供电，不经过 P03B 5 V，
且不得把 D36A 的 5 V 输出与系统 5 V 并联。

## 实车验收

至少重复 5 次，每次用 BLS 调平、把球恢复到 O 点后再双击 BLS，记录：

- +5 cm 最大位置；
- -5 cm 最终稳定位置；
- OLED 最终时间；
- 是否发生卡滞、振动或失步。

目标是两端误差绝对值均不超过 1 cm，最终稳定时间不超过 5 秒。一次只修改
一个参数，否则无法判断哪项改动产生了效果。
